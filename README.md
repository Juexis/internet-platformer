## Development
The concept of this game came to me after listening to [Xploshi's Rafflesia albums](https://youtu.be/VgvXNMJf2Ys?si=cBt8k26KlXVHwIQJ). I had originally aimed for a "Frutiger Aero" theming but later found that a "Windows 95-like" style would be easier for me to create.

Throughout the project, I learned:
- How to create custom states for the player's state machine
- Create animated & modular UI
- Implement a pausing system
- Create a save file system that saves the player's progress and loads it on subsequent opens
- Load levels in the background with threading, playing a loading animation on the main thread
